# @bili-agent-kit/cli

Use Bilibili from your terminal or scripts. Requires Node.js 22.18+, 24.11+ or 26+.

```sh
npx --yes @bili-agent-kit/cli@latest help
npx --yes @bili-agent-kit/cli@latest auth.login
npx --yes @bili-agent-kit/cli@latest auth.status
```

Scan the QR code with the Bilibili app and confirm on your phone.

See the [usage guide](https://github.com/Cansiny0320/bili-agent-kit/blob/main/docs/usage.md) for more commands.

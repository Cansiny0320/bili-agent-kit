## 范围

提供严格 TypeScript SDK、JSON CLI、stdio MCP，共用 B 站协议核心。保留 MIT 许可。无网页、云服务、模型、人格、调度器或 Codex 登录依赖。

使用 pnpm workspace、Vite+（Oxlint/Oxfmt）、packages/core、packages/cli、packages/mcp。Node 22.18+ / 24.11+ / 26+；依赖锁定到经核查的版本。

## 行为合同

- 读取视频、搜索、字幕、评论、私信历史、直播房间和近期弹幕；监听采用单次 poll + receipt/ack，调度由调用方控制。
- 评论发布/删除、私信发送、直播弹幕发送只能经过 dry run → 不可变草稿 → 可信管理员批准 → 执行。写入默认关闭，目标白名单在批准和执行时重新检查。
- 草稿绑定账号、完整内容摘要和幂等键；同键不同内容冲突。发送前落盘预留，断网、崩溃和不明响应不得自动重试；人工核查后可确认已发或未发。MCP 不暴露审批、策略、凭据和恢复接口，不接受 approved:true。
- 私信读取/发送只允许可信目标，发送前核查登录账号和互关。字幕 CDN 请求不带 Cookie，不跟随跨域重定向。
- 核心显式注入 credential provider、state store、fetch、clock。文件状态使用锁、原子替换和持久写入；状态损坏或锁繁忙则停止，不自动清空。持久限流预算、风控退避和登录暂停由所有入口共享。
- JSON envelope v1 统一成功与 typed error；不输出原始异常、Cookie、CSRF 或上游错误正文。外部内容属于不可信数据。
- 可选 ffmpeg 仅对明确指定的本地媒体抽帧，进程参数数组、无 shell、限制帧数和超时，不自动下载或安装 ffmpeg。

## 隔离边界

SDK 与 CLI 管理命令面向可信宿主，并非 shell 沙箱。能够读取凭据、修改策略/状态、调用管理员接口的进程拥有管理权限。宿主须隔离模型的 shell/文件访问和管理员身份。状态与草稿含私人内容，应放在访问受限目录，不共享到 Git。

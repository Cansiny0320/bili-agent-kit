# B 站能力补全：已批准设计

用户于 2026-10-26 明确批准本会话完整设计，并确认现有扫码登录继续保留。实现仅在当前仓库进行；不提交、推送、发布包或执行真实账号写操作。

## 范围与合同

- 内容发现：热门、排行、热搜、搜索类型/排序/时长、相关推荐、关注动态。
- 用户与个人内容：用户资料、投稿、关注/粉丝、收藏夹和内容、历史、稍后再看。
- 视频与评论：标签、视频弹幕、楼中楼、置顶评论、评论存在性、B 站 AI 总结和时间提纲。
- 消息与直播：回复/@/点赞通知，评论和直播增量读取、持久化去重与 receipt/ack，直播关键帧。
- 媒体：BV/AV/完整 URL/短链、分 P，下载视频、音频与切片、在线抽帧及拼图、字幕导出、文章 Markdown 导出、素材聚合、MCP 图片内容。
- 互动：收藏/取消、点赞/取消、关注/取关、评论点赞、投币、三连、视频弹幕；动态列表/详情、文字与图文动态发布/编辑/删除。
- 专栏与创作：专栏列表与详情、创作中心稿件指标；官方开放平台视频与文章稿件管理。
- 登录：保留 QR 登录，保存刷新凭据，可信 SDK/CLI 检查与刷新 Cookie。MCP 不开放登录、凭据或审批管理。

TypeScript core 是唯一协议实现；CLI/MCP 复用操作定义。保留既有操作名、输入和 envelope v1。分页操作显式返回下一页信息，限制每次工作量；资料是外部不可信数据。

新增写操作默认关闭，明确启用动作和目标白名单后仍需 preview/prepare/approve/execute。草稿绑定账号、目标、正文、附件摘要。多步上传持久化进度；不明确结果不自动重发，尤其投币、发布和删除。成功响应和最终审核通过分开。

状态升级保留旧草稿、游标、预算；新状态有版本检查，旧程序不能忽略新状态后重写。凭据刷新维持 UID 绑定，不清除风控/预算，不让旧会话草稿跨会话执行。

媒体须显式配置目录、大小和超时。仅跟随受控 B 站地址，CDN 不附带账号 Cookie；ffmpeg 使用受限进程参数，不自动安装。聚合结果记录来源、时间戳、缺失项，模型理解留给宿主。

事件消费沿用 poll/receipt/ack；完整分页成功后再推进游标；直播近期快照无法证明全量，输出覆盖范围。库不承担后台定时调度。

开放平台使用独立应用签名、token 和 scope，不能以扫码 Cookie 代替。实现及模拟验证可完成；真实开放平台验收依赖用户提供具有 ARC_BASE/ATC_BASE 等权限的应用与账号授权，不声称已线上通过。

## 目标与范围

接入八项能力：时间点抽帧与时间范围字幕/素材、合集和系列读取、可选本地 ASR、UP/合集增量事件、稍后再看添加移除、官方 OAuth 生命周期、官方创作数据与投稿 Webhook、官方直播事件。SDK core 为唯一业务实现，CLI/MCP 复用 operations。凭据管理、回调接收及长连接由可信宿主显式启动。

现有 Cookie、审批、限流、账号绑定和 pending/ack 机制保留。目录读取已有匿名 API 实测依据；官方功能需要应用权限，不能将模拟测试写成真实授权验收。

## 行为合同

- 帧提取支持最多 12 个时间点，或起止范围内按间隔采样；字幕范围保持原视频时间轴。materials 将范围传递给字幕和帧。
- 合集/系列提供目录、元数据及分页列表，保留上游分页信息，不改变视频 resolve 的含义。
- ASR 使用宿主配置的 whisper.cpp 与多语言模型；本地 FFmpeg 预处理，输出带原始时间偏移的分段和文本。显式调用，不自动上传音频或悄悄替代字幕。
- UP/合集事件第一次建立基线，随后发出新增成员；完整有界扫描、去重与 pending/ack；扫描不完整不推进。合集内旧视频新加入也产生事件，发布日期作为数据保留。公开读取支持匿名作用域。
- 稍后再看走现有 immutable draft → approve → execute；默认不允许新增写种类，目标为 video:<aid>。真实验收只做必要添加/移除并回读，不改其他互动内容。
- OAuth 凭据独立于 Cookie；管理接口不进入 MCP。刷新令牌单次使用，串行刷新并原子保存，不输出秘密。
- 创作数据要求 ARC_DATA；Webhook 验证原始正文签名、幂等入队，宿主负责 HTTPS 和快速应答。投稿回调只覆盖本应用投递的视频。
- 直播要求 LIVE_ROOM_DATA，宿主显式启动连接、HTTP/WS 心跳与有界重连；MCP 通过事件队列消费。服务请求不使用内容写入预算，但继续遵守服务限流及退避。
- 状态升级并备份旧版本，旧程序拒绝新格式，避免丢字段。无需注册远程应用、部署回调服务、commit、push 或创建 worktree。
